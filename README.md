## Описание проекта

Утилита для расчёта возраста человека в неожиданных единицах измерения.
Приложение принимает дату рождения в виде трёх отдельных чисел (день, месяц, год)
и вычисляет возраст в годах, месяцах, днях и минутах. Реализовано на Java
с использованием JavaFX и архитектурного паттерна MVC с активной моделью.
